# AeroRE continuation prompt

Continue the existing `YEAHMAN563/AeroRE` repository. Do not replace the
working native C++ implementation with a mock or web app, and do not redo
features already present. Read `README.md`, `docs/architecture.md`,
`docs/anti-anti-debug.md`, and the current tests first. Preserve the MIT
license and `THIRD_PARTY_NOTICES.md`.

## Current baseline

- C++20 PE32/PE32+ loader, Zydis decoder with fallback, deterministic parallel
  analysis, CFGs, xrefs, strings, SQLite IDB, CLI, Python binding, and MCP.
- Dear ImGui/DX11 Windows workbench with function list, IDA-style listing,
  conservative pseudocode, hex, CFG, xrefs, strings, imports/exports,
  registers, stack, console, and loopback MCP status/port.
- Windows debugger with process create/attach, software/hardware/guard-page
  breakpoints, nonblocking resume/step event pumping, and reversible detach.
- Configurable user-mode anti-anti-debug module with PEB/heap normalization,
  IAT query hooks, thread-hide modes, DR hygiene, exception neutralization,
  INI settings, audit logs, and x86/x64/WOW64 handling.
- VMProtect static LZMA reconstruction informed by VMPStatic, OEP tracing,
  virtualization/obfuscation assessment, and a conservative repair gate.
- IAT and export reconstruction plus combined `aerore.symbols.v1` JSON export.
- `AeroRE.sln` and `.vcxproj` files for Debug/Release x86/x64, CMake presets,
  and GitHub Actions coverage.
